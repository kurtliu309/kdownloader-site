Features

One window for the whole job.

Resolve a link, choose a format, watch the queue, then find the file in Completed. Each step has a card and a control.

Resolve

Paste a link, or ten

Drop in one URL or a block of text. KDownloader finds every link, resolves them together, and builds a card for each video or playlist.

youtube.com/watch?v=…Video
youtube.com/playlist?list=…Playlist
Formats

Every format, before you commit

Open the format table to see type, quality, container, codec and size. Download the merged file, video only, or audio only.

1920×1080 · 30 fps · 42.3 MB · avc1
FullVideo onlyAudio only
Queue

A queue that waits for you

Run 1 to 10 downloads at once. Pause, resume, and retry what failed; errors are grouped as login, network, file system, or ffmpeg.

Simultaneous downloads3
1510
LoginCookies stay local

Sign in only when a site asks

A built-in login window handles sites that need an account. Close it and resolving continues by itself. Login data never leaves this computer.

Login required · VimeoWaiting

Folders

Several folders, one naming rule

Keep a list of download folders and pick one per download. Add a prefix like VFX_{date}, or leave names untouched.

VideosCurrent
Videos\Shots
VFX_{date}_title.mp4
Completed

A library that tidies itself

Search titles, filter by folder, and keep playlists grouped. Deleted files go to the Recycle Bin; missing records clear in one click.

Delete → Recycle Bin

Setup

ffmpeg, handled

The first run fetches ffmpeg in the background. Tasks that need it wait their turn, and a retry button covers the rare failure.

InterfaceSwitch any time

English or Chinese, dark or light

Change language and theme whenever you like, or follow Windows. The light theme is warm paper, not a washed-out dark mode.

TrayRuns in back

Closing is not quitting

Send the window to the tray and downloads keep running. Click the tray icon to come back to the queue.

Supported sites

Works where you watch.

YouTube, Bilibili, Vimeo, X, Instagram and TikTok, plus thousands more through yt-dlp. When a video needs an account, KDownloader opens a login window and picks up where it left off.

YouTubeBilibiliVimeo X / TwitterInstagramTikTok
Plus the rest of the sites yt-dlp supports.
KDownloader does not bypass DRM, paywalls, or access controls. Download only content you have the right to keep.
